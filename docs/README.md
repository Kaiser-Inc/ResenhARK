# ResenhARK documentation

ResenhARK is a web platform for playing board-style games with friends: someone creates a room, shares a 5-letter code, and everyone plays from the browser with no account. These pages are for people who run, change or deploy it. They follow the [Diátaxis](https://diataxis.fr/) structure, so pick the page by what you need right now. The app itself is in Brazilian Portuguese; these pages are in English.
